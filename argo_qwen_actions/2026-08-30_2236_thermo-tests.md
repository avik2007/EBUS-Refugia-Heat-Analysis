## 1. What the function does (verified by running it)

`estimate_ohc_from_raw_bins(df, resolution_lat=1.0, resolution_lon=1.0,
resolution_time_days=30, depth_min=0, depth_max=2000, vertical_step=10,
min_coverage_pct=0.1)`

Input `df` columns (one row per raw measurement, all scalar cells):
`lat, lon, time_days, pres` (dbar), `depth` (m), `temp` (°C in-situ),
`psal` (PSU), `platform_number`.

Pipeline:
1. Per point: `SA = gsw.SA_from_SP(psal, pres, lon, lat)`,
   `CT = gsw.CT_from_t(SA, temp, pres)`, `rho = gsw.rho(SA, CT, pres)`,
   `cp = gsw.cp_t_exact(SA, temp, pres)`,
   **`energy_density = rho * cp * CT`**  ← Conservative temperature, not in-situ.
2. `lat_bin = (lat // 1.0) * 1.0 + 0.5`; same for `lon_bin`;
   `time_bin = (time_days // 30) * 30` (left edge, not centre).
3. Vertical layers: edges `arange(0, 2000+10, 10)`, centres `5, 15, …, 1995`.
   `pd.cut(depth, edges, labels=centres, include_lowest=True)`; points with
   `depth` outside `[0, 2000]` become NaN and are dropped **before** the
   `n_raw_points` count.
4. `groupby(['time_bin','lat_bin','lon_bin','z_idx'], observed=True)` → mean
   `energy_density`, first `platform_number`. Then `unstack('z_idx')` → wide grid
   whose **columns are only the depth centres that actually got data**
   (`n_cols` is that count, NOT 200).
5. Coverage gate per row: keep if
   `fill_rate (= non-NaN / n_cols) >= min_coverage_pct`
   **AND** any data in `iloc[:, :int(n_cols*0.10)]`
   **AND** any data in `iloc[:, int(n_cols*0.80):]`.
   → **A single isolated bin always passes** (its grid has no NaNs, so
   `fill_rate == 1.0` and both ends are populated). Exclusion only happens when
   two bins with different vertical coverage are unstacked together and one row
   ends up with NaNs at its top or bottom.
   If no row passes → return **`pd.DataFrame()` with `.empty is True`** (never
   `None`, never raise). Empty input and all-out-of-window input also return an
   empty frame.
6. `interpolate(axis=1, limit_direction='both')`, then
   `ohc = np.trapezoid(values, dx=10, axis=1)`.
7. Output columns:
   `time_bin, lat_bin, lon_bin, ohc, ohc_per_m, n_raw_points, platform_number, dist_to_coast_km`
   - `ohc_per_m = ohc / (depth_max - depth_min)` → `ohc / 2000` here (exact).
   - `n_raw_points` = count of in-window raw points for that (time,lat,lon) bin.
   - `platform_number` cast to `str` (dtype `object`); value is the first seen
     in row order.
   - `dist_to_coast_km` from `ae_utils.calculate_dist_to_coast` — **monkeypatched
     in tests** (see §2).
   - `ohc`, `ohc_per_m` are `float64`.

## 2. Fixtures — copy these verbatim into the test file

```python
import numpy as np
import pandas as pd
import pytest
import gsw

from ebus_core.argoebus_thermodynamics import estimate_ohc_from_raw_bins


# ---------------------------------------------------------------------------
# Isolation: the function calls ae_utils.calculate_dist_to_coast, which loads
# Cartopy Natural Earth coastline shapefiles (network + slow + non-deterministic).
# It is imported *inside* the function body as `from .ae_utils import ...`, so it
# resolves ae_utils.calculate_dist_to_coast at call time — patch it there. The
# stub returns a constant 123.0 km per point so tests can assert on the column.
# ---------------------------------------------------------------------------
@pytest.fixture(autouse=True)
def _stub_coast(monkeypatch):
    import ebus_core.ae_utils as ae_utils
    monkeypatch.setattr(
        ae_utils, "calculate_dist_to_coast",
        lambda lats, lons, *a, **k: np.full(len(np.atleast_1d(lats)), 123.0),
    )


# ---------------------------------------------------------------------------
# make_synthetic_df — build an Argo-like raw-measurement DataFrame, ONE ROW PER
# MEASUREMENT with scalar cells, shaped exactly like the loader output that
# estimate_ohc_from_raw_bins consumes.
#
#   coverage : which depth layers inside one lat/lon/time bin carry data
#       "full"      -> a point at every 10 m from 5 m to 1995 m (200 points)
#       "shallow"   -> only points shallower than `shallow_max_m`
#       "deep"      -> only points deeper than `deep_min_m`
#       "sparse"    -> `n_sparse` points spread evenly 5..1995 m (spans column)
#   temp_offset_C : adds a constant offset to the whole temperature profile
#   n_floats      : split the rows across this many platform_number values,
#                   interleaved by depth (tests float pooling)
#   n_bins        : stamp out this many bins, each shifted +1° lat, +1° lon,
#                   +30 days so it lands in its own box
#   lat0, lon0, time0 : location / time of the first bin
#   include_out_of_window : also add a point at depth -50 m and +2500 m
#
# temp profile: 4 + offset + 12*exp(-z/400)  => ~16 °C at surface, ~4 °C at depth
# pres from gsw.p_from_z so it is physically consistent with depth.
# ---------------------------------------------------------------------------
def make_synthetic_df(
    coverage="full",
    temp_offset_C=0.0,
    n_floats=1,
    n_bins=1,
    lat0=35.25,
    lon0=-124.75,
    time0=100.0,
    shallow_max_m=160.0,
    deep_min_m=1840.0,
    n_sparse=12,
    include_out_of_window=False,
):
    all_depths = np.arange(5.0, 2000.0, 10.0)  # 5, 15, ..., 1995
    if coverage == "full":
        depths = all_depths
    elif coverage == "shallow":
        depths = all_depths[all_depths < shallow_max_m]
    elif coverage == "deep":
        depths = all_depths[all_depths > deep_min_m]
    elif coverage == "sparse":
        idx = np.linspace(0, len(all_depths) - 1, n_sparse).round().astype(int)
        depths = all_depths[np.unique(idx)]
    else:
        raise ValueError(f"unknown coverage {coverage!r}")

    rows = []
    for b in range(n_bins):
        blat, blon, btime = lat0 + b, lon0 + b, time0 + b * 30.0
        zseq = depths
        if include_out_of_window:
            zseq = np.concatenate([[-50.0], depths, [2500.0]])
        for i, z in enumerate(zseq):
            rows.append({
                "lat": blat,
                "lon": blon,
                "time_days": btime,
                "pres": float(gsw.p_from_z(-z, blat)),
                "depth": float(z),
                "temp": 4.0 + temp_offset_C + 12.0 * np.exp(-z / 400.0),
                "psal": 34.5,
                "platform_number": f"f{b}_{i % n_floats}",
            })
    return pd.DataFrame(rows)


# ---------------------------------------------------------------------------
# reference_energy_density — recompute the pipeline's per-point energy density
# with the SAME GSW chain, so tests can derive expected OHC instead of hardcoding.
# `use_ct=True` -> rho*cp*CT (what the function does).
# `use_ct=False` -> rho*cp*t (the dormant in-situ convention) for the lock test.
# ---------------------------------------------------------------------------
def reference_energy_density(df, use_ct=True):
    sa = gsw.SA_from_SP(df["psal"].values, df["pres"].values,
                        df["lon"].values, df["lat"].values)
    ct = gsw.CT_from_t(sa, df["temp"].values, df["pres"].values)
    rho = gsw.rho(sa, ct, df["pres"].values)
    cp = gsw.cp_t_exact(sa, df["temp"].values, df["pres"].values)
    temp_term = ct if use_ct else df["temp"].values
    return rho * cp * temp_term
```

### Tier 1 — numeric

1. **`test_full_profile_ohc_matches_gsw_trapezoid`**
   `df = make_synthetic_df("full")`. Expected:

   Anchor: `ohc ≈ 5.11e10`, one output row.

2. **`test_ohc_per_m_identity`**
   Any passing run: `np.allclose(result["ohc_per_m"], result["ohc"] / 2000.0)`
   exactly. Also run once with `depth_min=100, depth_max=400` kwargs and assert
   the divisor tracks (`/ 300`).

3. **`test_ct_convention_is_used_not_in_situ_t`**
   `df = make_synthetic_df("full")`.
   `exp_ct = np.trapezoid(sort(reference_energy_density(df, True)), dx=10)`
   `exp_t  = np.trapezoid(sort(reference_energy_density(df, False)), dx=10)`
   Assert `np.isclose(result["ohc"].iloc[0], exp_ct, rtol=1e-6)` **and**
   `not np.isclose(result["ohc"].iloc[0], exp_t, rtol=1e-3)`.
   Also assert the two references really differ:
   `abs(exp_ct - exp_t) / exp_ct > 1e-3` (verified spread ≈ 0.0138) so the test
   is meaningful. Add a comment: this pins current intended behavior; the
   in-situ-`t` path is dormant (see `argoebus_thermodynamics.py`).

4. **`test_warmer_water_more_heat`**
   `warm = estimate_ohc_from_raw_bins(make_synthetic_df("full", temp_offset_C=2.0))`
   `base = estimate_ohc_from_raw_bins(make_synthetic_df("full"))`
   Assert `warm["ohc"].iloc[0] > base["ohc"].iloc[0]`.
   Anchor: `6.73e10 > 5.11e10`.

5. **`test_interpolation_fills_interior_nans`**
   NOTE: a lone bin's missing layers vanish as *columns* (not NaN) and are never
   interpolated — you only see interpolation when a sparse bin is unstacked
   beside a denser one that populates the shared columns. So:
   `full = make_synthetic_df("full")` at `(35.25, -124.75)`;
   `sparse = make_synthetic_df("sparse", n_sparse=40, lat0=36.25, lon0=-123.75)`
   (spans 5–1995 m, so it passes the gate). `df = pd.concat([full, sparse])`.
   Run once. Expect 2 rows. The sparse row (`lat_bin == 36.5`, `n_raw_points == 40`)
   has its 160 interior NaNs linearly filled before integration, so its `ohc` is
   within `rtol=1e-2` of the full row's `ohc` (smooth profile).
   Anchor: full `≈ 5.1105e10`, sparse-interp `≈ 5.1130e10`, rel diff `≈ 5e-4`.
