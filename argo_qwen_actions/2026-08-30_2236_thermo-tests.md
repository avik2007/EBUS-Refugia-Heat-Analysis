## Function under test — behavior contract

Signature:
```python
estimate_ohc_from_raw_bins(
    df,
    resolution_lat=1.0,
    resolution_lon=1.0,
    resolution_time_days=30,
    depth_min=0,
    depth_max=2000,
    vertical_step=10,
    min_coverage_pct=0.1,
)
```

### Required input columns on `df`
`lat`, `lon`, `time_days`, `pres` (dbar), `depth` (metres), `temp` (degC in-situ),
`psal` (PSU), `platform_number`.

### Processing stages (each is a test surface)

1. **Per-point thermodynamics (TEOS-10 / GSW).** For every row:
   - `SA  = gsw.SA_from_SP(psal, pres, lon, lat)`
   - `CT  = gsw.CT_from_t(SA, temp, pres)`
   - `rho = gsw.rho(SA, CT, pres)`
   - `cp  = gsw.cp_t_exact(SA, temp, pres)`
   - `energy_density = rho * cp * CT`   ← note: **Conservative** temperature `CT`,
     not in-situ `temp`. This differs from the dormant `calculate_thermodynamics`
     (which uses in-situ `temp`). Treat this as intended current behavior — do
     not "fix" it, do not add xfail markers. A test may assert the CT convention
     explicitly so the choice is locked.

2. **Spatial + temporal binning.**
   - `lat_bin = (lat // resolution_lat) * resolution_lat + resolution_lat/2`
   - `lon_bin = (lon // resolution_lon) * resolution_lon + resolution_lon/2`
   - `time_bin = (time_days // resolution_time_days) * resolution_time_days`
     (note: time bin is the **left edge**, not centre)

3. **Vertical binning.** `z_grid_edges = arange(depth_min, depth_max+vertical_step, vertical_step)`,
   centres at edge + step/2. Each point assigned to a layer via `pd.cut(depth, bins=edges, labels=centres, include_lowest=True)`.
   Points with `depth` outside `[depth_min, depth_max]` get NaN and are dropped.

4. **Synthetic profile.** `groupby(['time_bin','lat_bin','lon_bin','z_idx']).agg(energy_density='mean', platform_number='first')`,
   then `unstack('z_idx')` → wide grid, rows = (time,lat,lon), cols = depth centres.

5. **Coverage gate.** A row is kept only if ALL of:
   - `fill_rate = (non-NaN cols / n_cols) >= min_coverage_pct`
   - has at least one non-NaN value in the **top 10%** of columns (`iloc[:, :int(n_cols*0.10)]`)
   - has at least one non-NaN value in the **bottom 20%** of columns (`iloc[:, int(n_cols*0.80):]`)
   If no row passes → function returns an **empty `pd.DataFrame`** (`.empty is True`).

6. **Integration.** `interpolate(axis=1, limit_direction='both')` fills interior gaps,
   then `np.trapezoid(values, dx=vertical_step, axis=1)` → `ohc` (J/m^2).

7. **Output frame.** Columns: `time_bin, lat_bin, lon_bin, ohc, ohc_per_m,
   n_raw_points, platform_number, dist_to_coast_km`.
   - `ohc_per_m = ohc / (depth_max - depth_min)`
   - `n_raw_points` = count of in-window raw points per (time,lat,lon) bin
   - `platform_number` is cast to **str** dtype (object)
   - `dist_to_coast_km` from `ebus_core.ae_utils.calculate_dist_to_coast`

## Mandatory fixture / isolation setup

### 1. Monkeypatch the coastline dependency
`estimate_ohc_from_raw_bins` does `from .ae_utils import calculate_dist_to_coast`
**inside the function body**, so patch it at the source module:

```python
@pytest.fixture(autouse=True)
def _no_coastline(monkeypatch):
    import numpy as np
    import ebus_core.ae_utils as ae_utils
    monkeypatch.setattr(
        ae_utils, "calculate_dist_to_coast",
        lambda lats, lons, *a, **k: np.full(len(lats), 123.0),
    )
```
Reason: the real function pulls Cartopy Natural Earth 10 m coastlines and can
trigger a shapefile download — not allowed in unit tests.

### 2. Synthetic dataframe builder
Write a helper `make_synthetic_df(...)` that returns a valid input `df`.
Parameters it should support (keep it small, only what the tests below need):
- number of distinct (lat, lon, time) bins
- vertical coverage: full column vs surface-only vs deep-only vs sparse-spanning
- `temp` offset (to test warmer → more heat)
- number of floats (distinct `platform_number`) per bin
- `depth` grid (default `arange(5, 2000, 10)` so points land mid-layer)

Use physically plausible values: `psal` ~34.5, `temp` ~ 4–18 degC decreasing with
depth, `pres` ≈ `depth` (dbar ≈ m is fine for a fixture), `lat` ~35, `lon` ~ -125.
Derive `pres` with `gsw.p_from_z(-depth, lat)` if you want it exact — not required.

## Test cases

### Tier 1 — numeric / physics (tight tolerances)

1. **Constant full-depth profile → OHC = energy_density × range.**
   One bin, one float, points at every 10 m from `depth_min` to `depth_max` with
   identical `psal`/`temp`/`pres`-consistent values so `energy_density` is ~constant `E`.
   Assert `ohc ≈ E * (depth_max - depth_min)` (rtol ~1e-3) and
   `ohc_per_m ≈ E` (rtol ~1e-3). Compute `E` in the test by calling the same
   `gsw` chain directly on one representative point.

2. **`ohc_per_m` identity.** For any passing run,
   `ohc_per_m == ohc / (depth_max - depth_min)` exactly (`np.allclose` with default tol,
   or `==` on the Series). Use non-default `depth_min`/`depth_max` in one case.

3. **Linear vertical gradient → trapezoid equals analytic integral.**
   Build a profile whose `energy_density` varies ~linearly with depth (achieve via
   a linear `temp` gradient; verify linearity of `energy_density` numerically in
   the test, or assert with a looser rtol ~1e-2). Analytic integral of a linear
   field over `[a,b]` = `(f(a)+f(b))/2 * (b-a)`. Assert `ohc` matches (rtol ~1e-2).

4. **Warmer water → more heat.** Two runs from identical fixtures except
   `temp` + 2.0 degC everywhere. Assert `ohc` (same bin) strictly increases.

5. **CT convention lock.** On a single-point-per-layer bin, reproduce the
   pipeline's `energy_density` two ways — once with `CT`, once with in-situ `temp`
   — and assert the function's implied result matches the **`CT`** version, not
   the in-situ one. (Implied result = `ohc_per_m` for a constant profile, or
   back out the mean from `ohc`.) This pins the intended convention.

### Tier 2 — shape / smoke / contract (loose or exact-structural)

6. **Output columns + dtypes.** All of
   `{time_bin, lat_bin, lon_bin, ohc, ohc_per_m, n_raw_points, platform_number, dist_to_coast_km}`
   present. `ohc`, `ohc_per_m` float. `platform_number` dtype is object and each
   value is a `str`. `dist_to_coast_km` all equal 123.0 (from the monkeypatch).

7. **Bin arithmetic.**
   - point at `lat=32.3, lon=-124.7` with `resolution_lat=resolution_lon=1.0`
     → `lat_bin == 32.5`, `lon_bin == -124.5`
   - `time_days=95` with `resolution_time_days=30` → `time_bin == 90`
   - a negative-lon check because of floor division sign behavior
     (`-124.7 // 1.0 == -125.0` → `lon_bin == -124.5`).

8. **Multi-float pooling.** One (lat,lon,time) bin, 3 distinct `platform_number`s
   interleaved by depth → exactly **one** output row for that bin;
   `n_raw_points` == total in-window points; `platform_number` == the `first`
   value seen (document what "first" resolves to after groupby).

9. **Distinct bins → distinct rows.** Two well-separated (lat,lon,time) bins,
   each with a valid full profile → exactly 2 rows, correct `*_bin` values.

10. **Coverage gate — surface-only excluded.** Bin with data only in the top few
    layers (fails `has_deep`) → excluded. If it was the only bin → return value
    `.empty is True`.

11. **Coverage gate — deep-only excluded.** Mirror of #10 (fails `has_surface`).

12. **Coverage gate — sparse but spanning included.** Bin with `fill_rate` just
    above `min_coverage_pct` and at least one point in the top 10% and bottom 20%
    → row is kept; `ohc` is finite and > 0.

13. **No valid bins → empty frame.** All-surface-only input → returns
    `pd.DataFrame` with `.empty is True` (not `None`, not raise).

14. **Depth window filtering.** Points at `depth` = -50 and `depth_max + 500` are
    dropped; `n_raw_points` counts only in-window points; `ohc` unchanged vs the
    same fixture without the out-of-window points.

15. **NaN input handling — pin current behavior.** One or two rows with
    `temp=np.nan` (or `psal=np.nan`) mixed into an otherwise-valid bin. Run the
    function, observe what it does (GSW yields NaN `energy_density`; groupby
    `mean` skips NaN by default, so the layer mean may still be finite), and
    write assertions that lock **whatever actually happens today**. Add a comment
    stating this is characterization, not a spec.
